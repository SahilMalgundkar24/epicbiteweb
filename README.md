# Epic Bite

A recipe discovery website featuring a curated collection of simple, flavorful recipes designed to make everyday cooking easy and enjoyable.

**Live site:** [myepicbite.com](http://myepicbite.com/)

---

## Stack

| Layer | Technology |
|---|---|
| Framework | [Next.js 15](https://nextjs.org/) (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| Database / Backend | [Supabase](https://supabase.com/) |
| Analytics | Vercel Analytics |
| Icons | React Icons |
| Deployment | Vercel |
